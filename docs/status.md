# Current verification status

As of 2026-11-01, this prototype has real browser-model and database-readback
evidence for the fixed Pokémon fixture, not arbitrary user databases.

| Destination | Observed result | Remaining limitation |
|---|---|---|
| PostgreSQL | All 151 Pokémon and 218 type relations generated by Llama, stored and independently read back exactly equal to SQLite | One successful full run is not a reliability guarantee for new datasets |
| MariaDB | Same complete 151/218 source equality after destination readback | Same fixed-fixture limitation |
| MongoDB | All 151 documents and 218 embedded type relations generated by Llama, stored and independently read back exactly equal to SQLite | Five batches needed bounded individual-record recovery; this fixed-fixture success is not a guarantee for new datasets |

The working baseline uses WebLLM 0.2.87 and
`Llama-3.2-3B-Instruct-q4f32_1-MLC`, with explicit serialized structural schemas.
The recommended model passed isolated copy, relational and MongoDB singleton
cases. Earlier Qwen runs altered source values even in a two-field isolated copy.
That observation does not establish a universal model-quality or hardware claim.

## Validation evidence

The local interface now has a React presentation island, a decorative Three.js
Poké Ball and a light Pokédex-inspired theme shared by the source and stored-result
views. Decoration suspends for model activity and reduced motion; it does not
generate records or invoke database writes. The redesign was checked with 14
frontend tests and real-browser desktop/mobile checks. Full migration runs below
remain historical data evidence; they were not repeated just to take screenshots.

Importing database files or exported datasets and migrating arbitrary schemas is
future work. See the [roadmap](lecciones-aprendidas.md#8-interfaz-actual-y-próximos-hitos).

The current deterministic suites cover loading/cache controls, no-model gating,
JSON grammar requests, field/type/identity checks, bounded corrections, selective
recovery, no-write pilots, readback and rejected-input invariants. Real model
inference is distinct from mocked orchestration tests.

Raw downloaded model reports and private environment files remain local and are
not published. Initial baseline `286e5fe` preserves the working SQL implementation;
fix `47c0e84` adds MongoDB-only missing-document recovery without changing SQL
recovery behavior.

The subsequent real MongoDB run completed all 31 batches. Five batches required
individual recovery: IDs 51–55, 101–105, 111–115, 121–125 and 131–135. Twenty
records were regenerated in 32 individual attempts; total model calls were 76.
Independent read-only destination inspection confirmed all document fields,
sprite URLs and ordered type relations exactly matched SQLite, whose file hash
remained unchanged. These are real inference and stored-data observations,
separate from the 69 Node tests and 38 Python tests that passed for the fix.
