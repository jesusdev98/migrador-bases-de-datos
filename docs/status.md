# Current verification status

As of 2026-11-01, this prototype has real browser-model and database-readback
evidence for the fixed Pokémon fixture, not arbitrary user databases.

| Destination | Observed result | Remaining limitation |
|---|---|---|
| PostgreSQL | All 151 Pokémon and 218 type relations generated by Llama, stored and independently read back exactly equal to SQLite | One successful full run is not a reliability guarantee for new datasets |
| MariaDB | Same complete 151/218 source equality after destination readback | Same fixed-fixture limitation |
| MongoDB | First 50 Pokémon validated; full generation stopped at IDs 51–55 | After case changes were rejected, corrections returned only ID 51 and omitted four documents; full migration remains unverified |

The working baseline uses WebLLM 0.2.87 and
`Llama-3.2-3B-Instruct-q4f32_1-MLC`, with explicit serialized structural schemas.
The recommended model passed isolated copy, relational and MongoDB singleton
cases. Earlier Qwen runs altered source values even in a two-field isolated copy.
That observation does not establish a universal model-quality or hardware claim.

## Validation evidence

The current deterministic suites cover loading/cache controls, no-model gating,
JSON grammar requests, field/type/identity checks, bounded corrections, selective
recovery, no-write pilots, readback and rejected-input invariants. Real model
inference is distinct from mocked orchestration tests.

Raw downloaded model reports and private environment files remain local and are
not published. No successful complete MongoDB run is claimed. The next MongoDB
change will be isolated in a separate commit from this initial working baseline.
